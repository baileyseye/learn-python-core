Если вы уже знаете Java, Python покажется коротким. Но за краткостью стоят другие правила: нет обязательных типов, нет `main`, нет фигурных скобок, а коллекции ведут себя иначе.

## Быстрое сравнение

| Java | Python |
| --- | --- |
| `public class Main { public static void main(String[] args) }` | файл + `if __name__ == "__main__":` |
| `int x = 10;` | `x = 10` |
| `final int X = 10;` | константа по соглашению `X = 10` |
| `System.out.println("Hi");` | `print("Hi")` |
| `String.format("%s", name)` | `f"{name}"` |
| `for (int i = 0; i < n; i++)` | `for i in range(n)` |
| `for (String item : items)` | `for item in items` |
| `List<String> list = new ArrayList<>();` | `items = []` |
| `Map<String, Integer> map = new HashMap<>();` | `scores = {}` |
| `null` | `None` |
| `try/catch/finally` | `try/except/finally` |
| `interface` | `Protocol` или утиная типизация |
| `@Override` | не нужен |
| `record` / Lombok | `@dataclass` |
| `Optional<T>` | `T \| None` |
| Stream API | comprehension, `map`, `filter`, `itertools` |

## Что важно перестроить в голове

### 1. Типы принадлежат значениям

В Java переменная имеет фиксированный тип. В Python имя — просто ссылка на объект:

```python
value = 10
value = "теперь строка"   # допустимо
```

Аннотации `value: int` не проверяются в рантайме. Их читают IDE, mypy и pyright.

### 2. Отступы — синтаксис

Нет фигурных скобок. Блок — это одинаковый отступ, обычно четыре пробела. Смешали табы и пробелы — получили `IndentationError` или неожиданную логику.

### 3. Всё является объектом

Функции, классы, модули — объекты. Их можно передавать, хранить в словаре, возвращать. Отсюда декораторы и фабрики функций.

### 4. Коллекции — встроенные

Не нужно выбирать реализацию для `List`/`Map` в 90% случаев. Есть `list`, `tuple`, `dict`, `set`. Специализированные версии живут в `collections`.

### 5. Исключения не делятся на checked/unchecked

Любое исключение можно не объявлять в сигнатуре. Это не значит, что их не нужно обрабатывать — просто компилятор не заставит.

### 6. GIL и многопоточность

Потоки в Python полезны для ввода-вывода, но не для параллельных CPU-вычислений. Для CPU — `multiprocessing`, для сетевого ввода-вывода — `asyncio`.

В Python 3.13+ есть экспериментальная free-threaded сборка без GIL; в обычной сборке GIL остаётся и на неё рассчитаны советы выше.

## Что переносится из Java

- Привычка писать тесты.
- Ясные имена и небольшие функции.
- Разделение слоёв: контроллер, сервис, репозиторий.
- Понимание ООП, интерфейсов и композиции.
- Работа с Git и code review.

<Aside type="tip" title="Не тащите Java-церемонии в Python">
  Не нужно делать геттеры и сеттеры для каждого поля, создавать интерфейс на каждый класс
  и писать `class UserFactoryBuilder`. Начните с функции и dataclass — усложнить успеете.
</Aside>
